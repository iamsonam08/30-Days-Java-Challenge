# ☕ 30 Days Java Challenge
Welcome to my **30 Days Java Challenge!** 🚀

This repository documents my journey of learning Java from fundamentals to advanced concepts. Throughout this challenge, I will solve **2 coding problems every day**, strengthen my problem-solving skills, and build a solid foundation in Java for software development and technical interviews.


## 🎯 Goals

- Learn Java Fundamentals
- Master Object-Oriented Programming (OOP)
- Practice Data Structures & Algorithms (DSA)
- Build consistency through daily coding
- Prepare for technical interviews
