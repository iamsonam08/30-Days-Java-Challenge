## 🎯 Problem 1: Swap Two Numbers

### 📌 Objective

Swap two numbers without using a third variable.

### 💻 File

`SwapTwoNumbers.java`

### ▶️ Sample Input

```text
10
20
```

### ▶️ Output

```text
Before Swapping
a = 10
b = 20

After Swapping
a = 20
b = 10
```

### 📖 Concepts Used

- Arithmetic Operators
- Variables
