## 🎯 Problem 1: Bubble Sort

### Objective
Sort an array in ascending order using Bubble Sort.

### Example

Input:
5
64 25 12 22 11

Output:
11 12 22 25 64

### Time Complexity
O(n²)

### Space Complexity
O(1)

---

## 🎯 Problem 2: Selection Sort

### Objective
Sort an array in ascending order using Selection Sort.

### Example

Input:
5
64 25 12 22 11

Output:
11 12 22 25 64

### Time Complexity
O(n²)

### Space Complexity
O(1)

---

## 💡 Key Learning

Bubble Sort repeatedly swaps adjacent elements when they are in the wrong order.

Selection Sort repeatedly finds the smallest element from the unsorted part and places it at the correct position.
