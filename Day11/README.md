## 🎯 Problem 1: Reverse an Array

### 📌 Objective

Print the elements of an array in reverse order without creating another array.

### 💻 File

`ReverseArray.java`

### ▶️ Sample Input

```text
5
10 20 30 40 50
```

### ▶️ Output

```text
Reversed Array:
50 40 30 20 10
```

### 📖 Concepts Used

- Arrays
- Reverse Traversal
- for Loop

---

## 🎯 Problem 2: Sum and Average of an Array

### 📌 Objective

Calculate the sum and average of all elements in an array.

### 💻 File

`SumAndAverage.java`

### ▶️ Sample Input

```text
5
10 20 30 40 50
```

### ▶️ Output

```text
Sum = 150
Average = 30.0
```

### 📖 Concepts Used

- Arrays
- Traversal
- Accumulator
- Type Casting

---

## 📚 Key Learnings

- Arrays are indexed from `0` to `n - 1`.
- An array can be traversed in both forward and reverse directions.
- A running sum can be calculated using an accumulator variable.
- Explicit type casting can prevent unwanted integer division.
